知页 · 设置

填入 DeepSeek 的 API Key 即可开始使用。模型 Key 保存在浏览器扩展设置中（可能随浏览器同步），仅发送到你配置的模型接口。联网开启时，AI 会结合当前问题和视频素材生成关键词（也可手动填写），并发送到搜索服务，检索摘录与视频素材一并提交给模型。

2 · 总结偏好

思考强度仅对官方 DeepSeek 接口生效。上下文为素材与历史的文字字符预算；本轮问题、网页摘录和图片另计。快速联网关闭思考、最多 8K 输出、不自动续写；深入联网使用所选思考设置。达到上限可手动继续。

3 · 外观与字号

保存后侧栏立刻生效，不用重开。界面只用黑白灰，错误提示保留红色；字体固定 HarmonyOS Sans SC，本机没装会自动回落到系统字体。

4 · 人设

写给模型的自我介绍，最多 1000 字。只改称呼和语气——事实、数字、时间戳、引用编号、小节结构都不会变。

5 · 联网搜索

在侧边栏输入框左下角开启「联网搜索」。关闭时仅依据本视频回答；开启时显示本次搜索来源。检索失败会明确提示，不会假装已联网。

6 · 坚果云同步

只上传网页阅读记录和视频记忆，不含 API Key、不含设置、不含缓存片段。改动按条增量上传，不会整包重传。

使用提示

  • B站字幕需要登录：B站仅在登录状态下才下发 AI 字幕。用你自己的浏览器登录 B站即可， 插件会自动带上登录态，无需把账号密码给任何人。
  • 抖音基本没有字幕：抖音绝大多数视频没有字幕轨，插件会用「文案 + 话题 + 评论区」来生成总结， 并在结果里明确标注"基于推断"。这是平台限制，不是插件故障。
  • 刚安装后：已经打开的视频页需要按一次 F5 刷新，扩展脚本才会注入。
  • 更新扩展文件后：一定要到 edge://extensions 点一次「重新加载」。 否则侧边栏会是新版、后台脚本还是旧版，追问会一直卡住。出现「扩展后台还在跑旧版本」提示条时， 点里面的「重新加载扩展」按钮也能修复。
  • 快捷键：在侧边栏里按 Ctrl/Cmd + Enter 可直接生成总结。
